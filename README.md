# Y-ClipBoard — история буфера обмена Windows одной командой

Скрипт показывает историю буфера обмена Windows (ту, что открывается по `Win+V`).
Кладёшь его на GitHub — и запускаешь одной строкой из CMD/PowerShell, ничего
устанавливать не надо.

## Как запустить (после того как положишь на GitHub)

В CMD или PowerShell:

```
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/USER/REPO/main/Y-ClipBoard.ps1 | iex"
```

Замени `USER/REPO` на свои имя пользователя и название репозитория.
`irm` скачивает скрипт, `iex` его выполняет.

## Как выложить на GitHub (один раз)

1. Создай репозиторий на github.com (например `Y-ClipBoard`), публичный.
2. Загрузи туда файл `Y-ClipBoard.ps1` (кнопка **Add file → Upload files**).
3. Открой файл в репозитории, нажми кнопку **Raw** — скопируй ссылку из адресной строки
   вида `https://raw.githubusercontent.com/USER/REPO/main/Y-ClipBoard.ps1`.
4. Подставь эту ссылку в команду выше.

## Что делает скрипт

- Пытается прочитать историю буфера **напрямую** через WinRT
  `Clipboard.GetHistoryItemsAsync()` — даже если галка «Журнал буфера обмена»
  выключена (служба `cbdhsvc` часто ещё держит элементы в памяти).
- Если ничего не нашлось — включает журнал
  (`HKCU\SOFTWARE\Microsoft\Clipboard\EnableClipboardHistory`) и пробует снова.
- Печатает все элементы и сохраняет копию в `Рабочий стол\Y-ClipBoard.txt`.

Работает **только локально**, ничего никуда не отправляет.

## Ограничения

Windows держит максимум ~25 последних элементов и очищает их при перезагрузке.
Что реально удалено/уехало за пределы буфера службы — штатно вернуть нельзя.
Чтобы копить всё без ограничений и навсегда — нужен фоновый логгер (могу сделать отдельно).

## Y-ClipBoard-Memory.ps1 — попытка достать УДАЛЁННОЕ из памяти

Экспериментальный скрипт: находит процесс службы буфера обмена (`cbdhsvc`),
читает его память (`OpenProcess` + `ReadProcessMemory`) и выдёргивает оттуда все
текстовые строки. Среди них могут оказаться элементы, уже удалённые из Win+V, —
пока служба не перезаписала эту память.

```
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/USER/REPO/main/Y-ClipBoard-Memory.ps1 | iex"
```

Результат сохраняется в `Рабочий стол\Y-ClipBoard-Memory.txt` — открой и ищи
нужное через Ctrl+F.

Честно про ограничения:
- **Гарантий нет** — удалённое могло быть уже затёрто в памяти.
- В файле будет **много постороннего мусора** (строки интерфейса и т.п.).
- Может понадобиться запуск **от администратора** (если не хватит прав на чтение памяти).
- Это форензика собственной оперативной памяти на своём ПК; работает только локально.
